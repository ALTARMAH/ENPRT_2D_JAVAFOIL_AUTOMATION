================================================================================
                    AERO_AUTO v1.1 - QUICK START GUIDE (WINDOWS)
================================================================================

HOW TO RUN:
1. Standalone Application:
   - Extract the zip archive if you received the zipped package.
   - Double-click 'aero_ui.exe' (or 'aero_ui_standalone.exe') to launch.
   
2. From Python Source (Alternative):
   - Double-click 'run_ui.bat' or execute in terminal:
       python launcher.py ui

REQUIREMENTS:
- Windows 10 or Windows 11 (64-bit).
- Java Runtime Environment (JRE or JDK 8+):
  Java is required for running JavaFoil simulations.
  If not installed, download the free standard installer from:
  https://adoptium.net (Eclipse Temurin LTS .msi)

WHAT IS INCLUDED:
- Bundled JavaFoil jar engine and baseline airfoils library (s1223, e423, etc.)
- 7 Functional GUI Tabs: Configure, Airfoils, Campaigns, Results, Graphs, Optimizer, Themes & Settings.
- Interactive Results Table with 56 physical and regulatory columns, click-to-rank, and horizontal scroll.
- Full authentic aerodynamic graphs (Polars Cl/Cd/Cm, Velocity & Pressure Cp, Boundary Layer Cf & Delta).
- Direct CAD Export: 2D DXF and SVG geometry models.
- Complete official documentation in the 'docs/' directory:
    * docs/USER_MANUAL.pdf
    * docs/TECHNICAL_GUIDE.pdf
